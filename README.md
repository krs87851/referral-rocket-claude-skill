## How to use it

### Option 1 — Claude.ai Project (recommended, persists across chats)

1. Go to [claude.ai](https://claude.ai) → **Projects** → **New Project**
2. Click **Add content** → **Upload files**
3. Upload `referral-rocket-claude-skill.md`
4. Every chat in that project now has full Referral Rocket knowledge

### Option 2 — One-off chat

Drag and drop `referral-rocket-claude-skill.md` into any Claude chat window and ask your question.

### Option 3 — Claude Code (for developers)

Add this to your `CLAUDE.md`:
```
See referral-rocket-claude-skill.md for Referral Rocket platform documentation.
```
